====================================================
  FRIDAY BOT — COMMANDS (SIMPLE)
====================================================

PowerShell (Windows):
  .\setup.ps1              → one-time setup on a new laptop
  .\start_production.ps1   → stop old processes + open 5 windows (BOT+LISTEN+LIVE-PULL+LIVE-LOGIN+LIVE-STATUS)

Do NOT commit / sync via Git:
  .env, telegram_session/, tg-otp-automation-*.json, *.lock, state.json

Do NOT start production twice (causes 409 Conflict).
Do NOT run the bot from the Cursor terminal — use start_production.ps1.

  PRODUCTION (5 separate PowerShell windows)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  powershell -ExecutionPolicy Bypass -File .\start_production.ps1

  Window 1 = BOT
  Window 2 = LISTEN
  Window 3 = LIVE-PULL    (Sheet -> JSON, auto register)
  Window 4 = LIVE-LOGIN   (Sheet OTP column -> .session)
  Window 5 = LIVE-STATUS  (queue -> Sheet, delta push)

  Google Sheet columns (tab "Telegram Acc"):
    I  Status          — set Pending to trigger login
    J  Account Status  — script writes Active after success
    K  Session Friday  — script writes Active after success
    L  OTP             — staff fills SMS code during login
    M  2FA             — cloud / 2FA password (if Telegram account has 2FA)

  NEW SESSION LOGIN (no terminal typing)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1) Add row in Google Sheet (Phone, Group, User, …)
  2) Set column I Status = Pending
     (LIVE-LOGIN auto-registers JSON if phone not there yet, then login)
  3) LIVE-PULL also syncs all rows every ~45s (optional backup)
  4) Wait for SMS → fill OTP column (M); 2FA in column L if needed
  5) LIVE-LOGIN + LIVE-STATUS update J/K automatically

  Emergency manual only: login-all / login-all-shooter
  Daily OTP for staff: /login <account_id> in the bot
